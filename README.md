# にゃんともかんとも

`Vite + TypeScript + PixiJS` で作る、猫パーツのお掃除系マッチパズルです。

## 開発環境

- Node.js 22 LTS 推奨
- npm
- VS Code

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで Vite が表示したURLを開くと遊べます。

スマホ実機で確認する場合は、PCとスマホを同じWi-Fiにつないでから以下を実行します。

```bash
npm run dev:host
```

## PWA

このゲームはPWA対応済みです。スマホのブラウザで開いたあと、ホーム画面に追加するとアプリのように起動できます。

- iPhone: Safariで開く → 共有 → ホーム画面に追加
- Android: Chromeで開く → メニュー → ホーム画面に追加 / アプリをインストール

配布用ファイルは以下で作成します。

```bash
npm run build
```

生成された `dist` フォルダをHTTPS対応のWebサーバーに置くと、PWAとして配布できます。

## ルール

1. パーツをドラッグして、通過したマスと入れ替えます。斜め移動にも対応しています。
2. ドラッグ中、動かしているパーツが同じ猫種・同じ部位のパーツに重なると、重なったマスのパーツを掃除して消せます。
3. 同じ猫種の「頭」と「体」が上下左右で隣り合うと消えます。
4. 消えた分だけ上から新しいパーツが補充されます。

## レベル

最初は3種類の猫だけが出現します。スコアが一定値を超えるとレベルアップし、出現する猫種が1種類ずつ増えていきます。

| レベル | スコア | 猫種 |
| --- | ---: | ---: |
| 1 | 0 | 3 |
| 2 | 800 | 4 |
| 3 | 1,800 | 5 |
| 4 | 3,200 | 6 |
| 5 | 5,200 | 7 |
| 6 | 7,600 | 8 |
| 7 | 10,400 | 9 |
| 8 | 13,600 | 10 |

猫種は [src/main.ts](src/main.ts) の `CATS` 配列で差し替えできます。
